# Game manifests

One TOML file per ETI game id describing how to start the package on macOS
and Linux (Windows always runs the original `game_start.cmd`). See
`docs/COMPATIBILITY.md` for the format. Manifests marked with
`source = "macETI-LAN"` were derived from the MIT-licensed recipes of
https://github.com/kaapyth0n/macETI-LAN.
